Personal Finance Tracker

Theme: Finance, Budgeting & Personal Economics

📖 Project Description

The Personal Finance Tracker is a simple web-based application designed to help individuals understand, track, and manage their money. Users can add income and expense transactions, categorize them, and view their overall financial summary.

This project promotes financial awareness and teaches how everyday money decisions can be monitored using basic web technologies like HTML, CSS, JavaScript, and DOM manipulation.

Problem Statement

Many individuals do not actively track their income and expenses, which leads to poor budgeting and financial planning. Without a clear understanding of spending patterns, it becomes difficult to save money or make informed financial decisions.

This project provides a digital solution where users can:

Record their earnings and spending

Categorize transactions

View a summary of their financial balance

This encourages better budgeting habits and financial responsibility.

✨ Features Implemented

➕ Add income and expense transactions

🏷️ Categorize each transaction

📜 Display transaction history dynamically

❌ Delete individual transactions

📊 Automatic calculation of:

Total Balance

Total Income

Total Expenses

🔄 Real-time updates without page refresh

🧩 DOM Concepts Used

This project heavily uses JavaScript DOM manipulation, including:

document.getElementById() to select elements

addEventListener() to handle user actions

document.createElement() to generate dynamic content

Updating elements using innerHTML

Looping through arrays to render transaction data

Reading user input from form fields

Updating text content dynamically

▶️ Steps to Run the Project

Download or copy the project files

Ensure the project includes:

index.html

Linked JavaScript file (or script inside HTML)

Open the index.html file in any modern web browser

Start adding transactions to track income and expenses

No installation or server setup is required.

⚠️ Known Limitations

❌ Data is not stored permanently (refreshing clears transactions)

❌ No user login or authentication

❌ Limited categories (cannot add custom ones)

❌ No advanced financial reports or charts

🎯 Learning Outcomes

Through this project, students learn:

How to structure JavaScript logic

How to manipulate the DOM dynamically

How to perform calculations and data aggregation

How real-world finance concepts can be applied in programming
